# DeepShield

Multimodal Deepfake Detection using Visual AI, Audio AI and Fusion Engine.

## Features

* Visual deepfake detection
* Audio deepfake detection
* Multimodal fusion engine
* FastAPI backend
* React frontend dashboard
* Real-time confidence scoring

## Tech Stack

Frontend:

* ReactJS
* Axios
* CSS

Backend:

* FastAPI
* PyTorch
* OpenCV
* Transformers
* Wav2Vec2

Models:

* EfficientNet
* Wav2Vec2
* Fusion Model

## Run Locally

Backend:

uvicorn main:app --reload

Frontend:

npm start

## Future Scope

* Live webcam detection
* URL based analysis
